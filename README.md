### Project Description
A 3D fridge you can open and close right in the browser — except every time you open the door, it judges what's (or isn't) inside and roasts you for it.

### The Problem (that doesn't exist)
Nobody has ever needed their fridge to have an opinion about their eating habits. There is no shortage of judgment in anyone's life. We built one anyway.

### The Solution (that nobody asked for)
A fully interactive 3D fridge, built with nothing but HTML, CSS, and JavaScript, with hinged doors that swing open on click — and deliver a savage, unsolicited roast about your fridge contents (or lack thereof) every single time.

## Technical Details

### Technologies/Components Used
For Software:
- HTML
- CSS (3D transforms — `perspective`, `transform-style: preserve-3d`, `rotateY`/`rotateX`)
- JavaScript (vanilla, no frameworks)
- No external libraries — no Three.js, no build tools, no dependencies

For Hardware:
- N/A — this is a pure software project, no hardware components used

### Implementation
For Software:

# Installation
No installation or build step required — it's a single static HTML file.
```
git clone <l>
cd <your-repo-folder>
```

# Run
Just open the file directly in any modern browser:
```
[https://nthaivide.vercel.app/]      # macOS
[https://nthaivide.vercel.app/]     # Windows
[https://nthaivide.vercel.app/]  # Linux
```
Or serve it locally if you prefer:
```
python3 -m http.server 8000
# then visit http://localhost:8000/fridge.html
```
